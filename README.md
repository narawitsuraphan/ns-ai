# NS AI

โปรแกรมเทอร์มินัลหลายหน้าจอสำหรับ Windows 11 — ใช้ cmd หรือ PowerShell ได้หลายหน้าพร้อมกันในหน้าต่างเดียว

## ดาวน์โหลด

ไปที่แท็บ **Releases** ด้านขวา แล้วดาวน์โหลดไฟล์ `NS-AI-Setup-1.0.0.exe`

## การติดตั้ง

1. ดับเบิลคลิกไฟล์ที่ดาวน์โหลด
2. ถ้า Windows ขึ้นคำเตือน SmartScreen ให้กด **More info** แล้ว **Run anyway** (ตัวติดตั้งยังไม่ได้ลงนามดิจิทัล)
3. เปิดโปรแกรมได้ทันทีจากไอคอนบน Desktop หรือ Start Menu

## การอัปเดต

โปรแกรมจะตรวจเวอร์ชันใหม่จากที่เก็บนี้ให้เอง เปิด **Settings > Updates** แล้วกด **Check now** ได้ตลอด
ข้อมูลโปรเจกต์และการตั้งค่าของคุณถูกเก็บไว้ในโปรไฟล์ผู้ใช้ Windows จึงอยู่ครบทุกครั้งที่อัปเดต

## ฟีเจอร์

- เทอร์มินัลหลายหน้าจอในหน้าต่างเดียว สลับรูปแบบกริดได้
- ใช้ PowerShell, Command Prompt, WSL และ Git Bash พร้อมกัน
- เปิดได้หลายโปรเจกต์ ทุกเซสชันเริ่มที่โฟลเดอร์ที่ถูกต้อง
- เรียกใช้ Claude Code และ Codex ได้โดยตรง พร้อมไอคอน
- ธีมมืดเป็นค่าเริ่มต้น มีโหมดสว่างให้เลือก
- หน้าตั้งค่าและหน้าผู้พัฒนา
- ทำงานได้แบบออฟไลน์
