# NS Deck

**Multiple terminals. One window.**

NS Deck keeps live terminal sessions together, organised by project folder, and makes Claude Code and Codex easy to open from the same workspace. Version 1.0.3 supports Windows and Linux.

## Download

- [Windows installer — NS-Deck-Setup-1.0.3.exe](https://github.com/narawitsuraphan/ns-ai/releases/latest/download/NS-Deck-Setup-1.0.3.exe)
- [Linux x64 AppImage — NS-Deck-1.0.3.AppImage](https://github.com/narawitsuraphan/ns-ai/releases/latest/download/NS-Deck-1.0.3.AppImage)

Downloads are free and do not require an account.

## Features

- Run several terminals side by side and switch between flexible grid layouts.
- Organise sessions by one project or many project folders.
- Use supported shells together: PowerShell, Command Prompt, WSL and Git Bash on Windows; Bash, Zsh, Fish and PowerShell 7 on Linux.
- Launch Claude Code or Codex with one click, or start either agent yourself and let NS Deck recognise it automatically.
- Copy and paste multi-line text with a full terminal context menu.
- Choose a calm dark theme or a light theme.
- Check for and install updates without losing projects, preferences or layouts.

## Requirements

- Windows 10 version 21H2 or newer, or a Linux x64 desktop that supports AppImage.
- Claude Code and Codex are optional and must be installed separately to use their launch buttons.
- Linux distributions without FUSE 2 compatibility may need the matching system package.

## Installation

On Windows, download the installer and open it. The installer is not code-signed, so SmartScreen may show a warning; this is expected.

On Linux, download the AppImage, mark it executable in your file manager, then open it. No source code or separate runtime is required.

## Updates and privacy

NS Deck checks for updates and offers them inside the app. Projects and preferences stay in your user data folder across updates. The application runs on your computer; this public repository is used to distribute releases and does not contain the app's source code.
