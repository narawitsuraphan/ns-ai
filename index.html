Questions

Will I lose my data when I update?

No. Your projects, theme and layout live in your Windows user profile, separate from the folder the app is installed in, so they survive updates. If you installed an earlier version under its previous name, those settings are carried over automatically the first time you open this one.

Why does Windows warn me during installation?

The installer does not have a paid digital certificate yet. That is not a sign the app is harmful. Choose More info, then Run anyway.

Codex says "start the Windows daemon from a non-elevated terminal"

NS Deck already handles this. Open Settings, then Agents, and use Fix Codex for plain terminals. After that the codex command works normally everywhere, including a Command Prompt you open yourself. A backup of your Codex config is kept and the change can be undone.

Do I need Claude Code or Codex installed?

They are optional. If they are already on your machine the launch buttons work right away; otherwise the app clearly marks them as not found and everything else keeps working.

Does it send anything to the internet?

No. The app runs entirely on your machine. It only reaches out to check for its own updates from this repository.

Is the source code available?

This repository is used only to distribute the application and contains no source code. Feedback and bug reports are welcome through the issue tracker.
